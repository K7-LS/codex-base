# Lazy tool capabilities

Codex-base маршрутизирует работу по capability ID, а не по имени конкретного
MCP-сервера или plugin.

## Правила

- Ни один внешний инструмент не обязателен для простого разговора.
- Навык объявляет `required_capabilities` в каталоге.
- Инструмент подключается lazy только после выбора навыка.
- База не устанавливает, не включает и не авторизует MCP/plugins сама.
- `doctor` проверяет установленную базу и её соответствие канону; например,
  `CANONICAL` / `CANONICAL_WITH_LOCAL_EXCEPTIONS` описывают состояние установки.
  Это не проверка списка инструментов host, соединения или выполнения операции.
- Различай наличие настройки, обнаружение инструмента, успешный вызов и приёмку
  результата. Для каждого вывода нужно соответствующее доказательство.
- Если обязательная операция недоступна, проверь разрешённый эквивалент по этой
  операции. Если его нет, назови `BLOCKED` для зависимой части; необязательная
  возможность не блокирует всю задачу. Не выдавай отсутствие проверки за успех.

Типовые capability: `document.word.read`, `spreadsheet.read`, `pdf.read`,
`web.fetch`, `web.search`, `web.browser.interact`, `cad.read`,
`revit.inspect`. Конкретный provider выбирается текущим host и может меняться
без изменения методологии навыка.

Для передачи крупного процесса предметному модулю читай соседний
[[module_contract]] (`module_contract.md`): там определены входы, разрешения
и проверка возвращаемого результата.
