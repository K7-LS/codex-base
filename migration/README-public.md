# Переход на анонимный Sync Base

Установленный updater 0.2.6 требует вход в GitHub и поддерживает старый
протокол. Для первого перехода нужен комплект нового updater, полученный
через доверенный корпоративный канал. В комплекте сохраняется папка
`sync-base` целиком, включая `tools`, `runtime` и `sync-policy.json`.
Доверие к комплекту устанавливается до запуска, независимо от контрольной
суммы, лежащей рядом с ним.

После подтверждения происхождения комплекта запускается его штатная команда:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '<проверенная папка>\sync-base\tools\sync_base.ps1'
```

Обновлятор использует публичный GitHub API и проверяет подпись релиза,
точные байты пяти файлов и происхождение каждого файла. `gh` нужен для
TUF и проверки локальных аттестаций. Вход в GitHub и токен не требуются.
Foundation строит план, применяет пакет, запускает doctor и откатывает
установку при его ошибке. После успешного перехода вызывается обычный
`$sync-base` из установленной базы.

До выдачи сотрудникам отдельно проверить, как доверенный комплект попадёт
на ПК, где установлен только updater 0.2.6. Отдельная доставка обязательна
для первого запуска. Статус пакета определяется живой приёмкой и публикацией.
