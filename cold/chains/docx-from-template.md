# chain:docx-from-template

## Назначение

Заполнение копии Word-шаблона с сохранением его структуры и оформления:
поиск полей, сопоставление значений с источниками, запись и проверка результата.
Средства чтения и записи выбирай через `word-helper` по реально доступным
инструментам host; capability обозначает операцию, а не вызываемый API.

## Шаги

### Stage 1 — read template (collect)

Прочитать шаблон средством с capability `document.word.read`: абзацы, таблицы,
колонтитулы и другие области, где расположены заполняемые поля. Найти
плейсхолдеры `{{name}}` / `[[name]]`, в том числе разорванные на runs, и поля
другого вида. Записать их расположение и формат; исходный файл сохранить.

**Verify:** заполняемые места определены по шаблону и заданию. Отсутствие
скобок не означает неправильный шаблон: это могут быть обычные строки,
поля Word или элементы управления. Уточнить только оставшуюся неоднозначность.

### Stage 2 — collect values (extract)

Сопоставить поля с уже переданными значениями, документами и принятыми
решениями. Для каждого значения сохранить источник. Через доступный
инструмент вопросов host или краткий вопрос уточнить только недостающие
или противоречивые данные; размер группы вопросов — по ограничениям host.
Уже известные сведения и выбранный пользователем вариант не спрашивать снова.

**Verify:** для каждого плейсхолдера есть значение или явное «оставить
пустым».

### Stage 3 — render (act)

Средством с capability `document.word.write` подставить согласованные значения
в копию шаблона в разрешённом рабочем каталоге. Способ должен сохранять
runs, стили, поля, объединения, изображения и связи, которых правка не касается.
Возможность только чтения не выполняет запись. Если подходящей записи нет,
проверить допустимый эквивалент по этой операции; иначе открыто назвать блокер.

**Verify:** после сохранения повторно прочитать каждое заполняемое место;
значения и согласованные пустые поля соответствуют карте подстановок.
Не осталось незаполненных целевых полей; буквальные скобки исходного текста
не считать ошибкой автоматически. Неизменяемые части сохранились.

### Stage 4 — format + save

Сохранить оформление шаблона и заданный формат выдачи; применить
`stroy-formatting`, когда нужно сопоставить результат с образцом. Уточнять стиль
только при существенной неоднозначности, которую не разрешают шаблон и задание.

**Verify:** документ открывается и read-back совпадает с источниками.
Содержание по источникам проверяет `auditor`, структуру DOCX — `word-checker`;
постраничный рендер и визуальная проверка подтверждают сохранение вёрстки.
После исправления проверить конечный файл повторно. Успешное чтение или
наличие файла не заменяет эти проверки; недоступный гейт не считать PASSED.

## Когда НЕ использовать

- Если требуется только копирование без заполнения — выполнить его напрямую.
- Если шаблона нет — определить допустимость создания нового документа;
  не вызывать отсутствующую цепочку `docx-from-scratch` и не выдумывать бланк.
- Для большого числа недостающих значений можно предложить таблицу вместо
  серии вопросов. Уже переданную таблицу использовать без повторного запроса.
